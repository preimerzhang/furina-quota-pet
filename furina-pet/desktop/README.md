# 芙宁娜桌面额度宠物

双击 `启动芙宁娜.cmd`。芙宁娜出现在桌面右下角，重复启动不会创建多个宠物。

- 单击芙宁娜：实时读取当前 Codex 账号额度，显示剩余百分比、重置时间和本次更新时间。
- 按住拖动：移动宠物；拖动不会触发额度查询。
- 鼠标靠近：芙宁娜会转动视线。
- 双击宠物：随机挥手或跳跃，并显示可关闭的角色风格短语。
- 右键“设置”：调整大小（60%–180%）、视线互动、短语、主动互动频率和全屏隐藏。
- 托盘菜单：显示、隐藏、查看额度、设置或退出；双击托盘图标显示宠物。
- Ctrl+Alt+F10：快捷显示或隐藏；快捷键被其他程序占用时仍可使用托盘。
- 右键：查看额度、关闭面板或退出宠物。面板也可用 × 或 Esc 关闭。

拖动后自动保存位置，退出和保存设置时也会记录大小与偏好，下次启动恢复。配置文件为同目录 `settings.json`，只保存在本机，不上传到 GitHub。显示器断开后会将宠物移回可见区域。

开机启动默认关闭，勾选设置中的“登录 Windows 后自动启动”并保存即可启用，取消勾选并保存即可关闭。仅修改当前用户的 Windows Run 启动项 `FurinaQuotaPet`；移动项目目录后需关闭并重新开启此项。

全屏自动隐藏默认开启，退出全屏后恢复；手动隐藏会保持隐藏，需从托盘或快捷键恢复。主动互动默认仅双击，可设为每 1、2 或 5 分钟。双击短语为本项目原创角色风格表达，不是游戏官方台词。

单击查询会等待系统双击判定时间（通常约半秒），以避免双击互动误触查询。

### 提醒、番茄钟与多屏

在右键“设置”中的“提醒、番茄钟与显示器”，或托盘“提醒与专注”打开控制面板。

- 低额度提醒默认关闭，可设 1%–50% 阈值。开启后启动约 5 秒及每 5 分钟读取一次，手动查询也会检查。低于阈值时，每个额度窗口在同一重置周期只提醒一次，重启后仍去重；重置时间未知时按本地日期去重。更改阈值会重新判定。未知额度与查询失败不会提醒。通知展示受 Windows 通知及专注助手设置影响。
- 专注默认 25 分钟、休息 5 分钟，可调整为 1–120 / 1–30 分钟，支持开始、暂停、继续、结束。专注期间暂停角色互动，完成后提醒并开始休息；休息结束提醒，不自动开始下一轮。手动额度查询仍可用。计时不跨应用重启保留，隐藏宠物后继续计时。
- 可选择显示器并移动宠物。拖动结束时在距工作区边缘 20 像素以内吸附，可关闭；支持负坐标和不同显示缩放，位置保存为窗口实际坐标。显示器断开或布局变化后，将宠物移回最近显示器的可见区域，额度面板跟随当前显示器。

多屏边界和负坐标已用模拟布局测试；当前电脑验证了实际窗口定位，不同缩放比例的多屏组合仍需实机验证。

查询期间显示工作动画，成功时挥手；查询失败会提示重试。未知额度显示“未知”。额度属于整个账号。

复用已制作的完整芙宁娜素材（9 组动画及 16 个视线方向）。这是独立 Windows 桌面窗口，动画由本窗口交互驱动；原有 Codex 内置宠物仍可使用。

运行需要已安装并使用 ChatGPT 账号登录的 Codex，以及此电脑的 Codex Python 运行时。没有复制登录凭据，也不会调用额度重置或购买功能。通过官方 [app-server 协议](https://learn.chatgpt.com/docs/app-server) 的 `account/rateLimits/read` 读取额度。

自动寻找当前用户的 Codex Python 运行时，然后寻找 PATH 中的 `python.exe`；也可通过 `furina.ps1 -PythonExe "Python 的完整路径"` 指定。查询脚本只使用 Python 标准库。启动异常可查看同目录 `error.log`。
